# NodeCast TV Plus v2.5.2

NodeCast TV Plus v2.5.2 is a focused security and playback-reliability patch release. It bounds authenticated history and provider-metadata work and ensures Continue Watching preserves manually selected Movie and Series positions.

---

### Highlights

- Bound retained watch history and authenticated history/recent-content requests.
- Rate-limit history mutation and provider-metadata operations while coalescing identical concurrent Xtream requests.
- Remove an obsolete dynamic Xtream route and avoid returning raw upstream error details.
- Save forward and backward seeks immediately instead of waiting for the periodic history checkpoint ([#272]).
- Preserve the requested content position while a replacement transcode session starts ([#272]).
- Save final progress before Back navigation, including while playback is paused ([#272]).

---

### Upgrade from v2.5.1

Back up the existing `/app/data` volume, pull the release image from either registry, and recreate the container with the same volume and deployment secrets:

```bash
docker pull ghcr.io/mikaelkw/nodecast-tv-plus:2.5.2
```

or:

```bash
docker pull mikaelkw/nodecast-tv-plus:2.5.2
```

No manual database migration is required. Keep the existing strong, distinct `JWT_SECRET` and `SESSION_SECRET` values. If authenticator-app 2FA is enabled, also preserve the existing `TOTP_ENCRYPTION_KEY`.

Matching stable tags are published to both registries:

- `2.5.2` — this exact release
- `2.5` — newest compatible 2.5 patch release
- `latest` — newest stable release

To roll back, stop the upgraded container, restore the pre-upgrade data backup, and recreate the container with `2.5.1` and the existing deployment secrets.
