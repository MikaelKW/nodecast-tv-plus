# NodeCast TV Plus v2.5.4

NodeCast TV Plus v2.5.4 is a focused stabilization release for provider compatibility, very large catalogues, cross-browser remux audio, loading feedback, content visibility, and request controls.

---

### Highlights

- Restore compatibility with Xtream gateways that reject header-minimal API requests while retaining the existing outbound security checks ([#308]).
- Keep searches in a loading state until Live TV, Manage Content, Movies, Series, or TV Guide data is ready, then apply the retained query ([#305]).
- Show the conventional indeterminate/minus state when only part of a Manage Content group is visible ([#295]).
- Load provider catalogues containing hundreds of thousands of entries in Chromium without a `Maximum call stack size exceeded` failure ([#326]).
- Restore Firefox audio for AAC MPEG-TS remux streams while retaining Chromium's automatic remux behavior ([#323]).
- Keep FFmpeg discovery reliable when the optional bundled package is unavailable ([#316], [#318]).
- Add focused per-account limits to selected OIDC and administrative operations ([#306]).

---

### Upgrade from v2.5.3

Back up the existing `/app/data` volume, pull the release image from either registry, and recreate the container with the same volume and deployment secrets:

```bash
docker pull ghcr.io/mikaelkw/nodecast-tv-plus:2.5.4
```

or:

```bash
docker pull mikaelkw/nodecast-tv-plus:2.5.4
```

No manual database migration is required. Keep the existing strong, distinct `JWT_SECRET` and `SESSION_SECRET` values. If authenticator-app 2FA is enabled, also preserve the existing `TOTP_ENCRYPTION_KEY`.

Matching stable tags are published to both registries:

- `2.5.4` — this exact release
- `2.5` — newest compatible 2.5 patch release
- `latest` — newest stable release

To roll back, stop the upgraded container, restore the pre-upgrade data backup, and recreate the container with `2.5.3` and the existing deployment secrets.

- Application, authentication, request-control, Xtream compatibility, loading-state, content-group, large-catalogue, remux, browser/media, mobile WebKit, reverse-proxy subpath, CodeQL, dependency, Docker, release-metadata, vulnerability, and migration checks passed.
- The automated release gate verifies supported upstream v2.1.1 and 2.1.4 migrations and an upgrade from the published Plus v2.5.3 image.
- The exact combined testing image passed controlled local and production-provider validation covering MFA, Xtream and M3U sources, Direct HLS, remux and transcoded playback, Firefox and Chromium audio, very large catalogues, search during loading, partial group state, TV Guide, Movies, Series, restart persistence, and application responsiveness.
