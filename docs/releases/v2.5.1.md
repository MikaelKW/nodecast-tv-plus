# NodeCast TV Plus v2.5.1

NodeCast TV Plus v2.5.1 is a compatibility, performance, and security patch release. It fixes AAC-in-MPEG-TS remux failures, improves large-provider startup and TV guide loading, and tightens several application trust boundaries.

---

### Highlights

- Remux compatible AAC-in-MPEG-TS live streams without audio re-encoding or FFmpeg mux failures ([#258]).
- Retry an affected Xtream channel with MPEG-TS output when its HLS response is incompatible, without changing the source-wide preference ([#258]).
- Make large provider catalogues usable sooner through lightweight now-playing data, lazy full-guide loading, concurrent source work, bounded retries, and database indexing ([#261]).
- Keep later sources available when an earlier provider fails or times out during startup ([#261]).
- Strengthen media and network destination validation, cache and transcode containment, session controls, TOTP limits, proxy trust, and media-process resource bounds.
- Pin third-party GitHub Actions to reviewed commit identifiers.

---

### Upgrade from v2.5.0

Back up the existing `/app/data` volume, pull the release image from either registry, and recreate the container with the same volume and deployment secrets:

```bash
docker pull ghcr.io/mikaelkw/nodecast-tv-plus:2.5.1
```

or:

```bash
docker pull mikaelkw/nodecast-tv-plus:2.5.1
```

No manual database migration is required. Keep the existing strong, distinct `JWT_SECRET` and `SESSION_SECRET` values. If authenticator-app 2FA is enabled, also preserve the existing `TOTP_ENCRYPTION_KEY`.

Matching stable tags are published to both registries:

- `2.5.1` — this exact release
- `2.5` — newest compatible 2.5 patch release
- `latest` — newest stable release

To roll back, stop the upgraded container, restore the pre-upgrade data backup, and recreate the container with `2.5.0` and the existing deployment secrets.

### Validation

- Application, authentication, TOTP, OIDC, dependency, proxy, remux, Xtream fallback, large-provider, browser/media, mobile WebKit, reverse-proxy subpath, Docker, release-metadata, and migration checks passed.
- The automated release gate verified supported upstream v2.1.1 and 2.1.4 migrations and an upgrade from the published Plus v2.5.0 image.
- Hands-on validation covered MFA login and recovery after an incorrect code, a real provider affected by the AAC remux failure, Direct HLS, delayed transcoding, immediate large-provider channel and EPG availability, Movie and Series seeking, audio and subtitle switching, restart persistence, and application responsiveness after playback.

---

### Security

This release contains defense-in-depth corrections for media and network destination handling, temporary-file containment, resource limits, proxy trust, authentication attempt bounds, and session lifecycle behavior. Review the published [security advisories](https://github.com/MikaelKW/nodecast-tv-plus/security/advisories) for affected-version and remediation details.
